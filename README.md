# قاعة الشرق الأوسط للإحتفالات

موقع عربي وإنجليزي لقاعة الشرق الأوسط للإحتفالات في جدة. يبدأ كل تبويب جديد بالعربية والوضع الفاتح، مع إمكان تغييرهما أثناء الزيارة. يتضمن صفحة رئيسية، معرض صور وفيديوهات، ونموذج طلب يفتح رسالة واتساب جاهزة.

## التشغيل محلياً

الموقع ثابت ولا يحتاج إلى تثبيت حزم. شغّل خادماً محلياً في هذا المجلد، مثلاً:

```sh
python -m http.server 8080
```

ثم افتح `http://localhost:8080/`.

## الملفات

- `index.html`: الصفحة الرئيسية.
- `gallery.html`: معرض الصور والفيديوهات.
- `styles.css`: التصميم والتجاوب والحركة.
- `main.js`: اللغة والوضع والقائمة ونموذج طلب المناسبة.
- `gallery.js`: عرض الوسائط ونافذة التكبير.
- `assets/media-sources.json`: قائمة مواد المعرض ومصادرها.
